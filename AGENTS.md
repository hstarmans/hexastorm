# Agent Instructions & Rules

## Math & Equation Formatting
- Antigravity IDE does NOT render LaTeX formulas (`$`, `$$`, `\text`, `\frac`, `\mu`, `\times`, etc.).
- **NEVER** output math or units in LaTeX syntax or enclosed in dollar signs (`$...$`, `$$...$$`).
- Always format equations, numbers, and units using:
  - Clean plain text.
  - Standard Unicode characters (e.g., µm, °, ×, ÷, ±, Δ, ≈, ≤, ≥, x̄).
  - Markdown inline code (`10.583 µm/px`) or code blocks (`f_orth = delta_y - median(delta_y)`).
