# Math & Equation Formatting Rules

- Antigravity IDE UI does NOT render LaTeX formulas (`$`, `$$`, `\text`, `\frac`, `\mu`, `\times`, etc.).
- **NEVER** use LaTeX syntax or dollar-sign enclosures (`$...$`, `$$...$$`) in chat responses or generated documentation.
- Always format equations, numbers, and units using:
  - Clean plain text.
  - Standard Unicode characters (e.g., µm, °, ×, ÷, ±, Δ, ≈, ≤, ≥, x̄).
  - Markdown inline code (`10.583 µm/px`) or code blocks (`f_orth = delta_y - median(delta_y)`).
